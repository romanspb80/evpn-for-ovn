# Cilium scope decision

No maintained Cilium adapter, Cilium caller of the Framework APIs, or concrete
Cilium-specific defect/contribution was identified in the audited source and
planning material. No implementation task or upstream issue/PR is invented
to populate this page.

Generic BGP interoperability alone would not demonstrate EVPN/OVN
integration or shared dataplane ownership. Revisit only when a specific
consumer requirement and compatible route/ownership contract exist; until
then Cilium is outside the first-release feature set.
